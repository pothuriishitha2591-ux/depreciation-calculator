# Depreciation Calculator (Enhanced)

This project is a full-stack depreciation calculator with detailed schedules and charts.
Currency is Indian Rupees (₹).

## Features
- Straight-line, Declining balance (custom factor), SYD, Units of production
- Server-side validation with descriptive error messages
- Detailed schedule: Beginning book value, depreciation percent, depreciation amount, accumulated depreciation, ending book value
- Chart (Chart.js) showing beginning book value and depreciation amount per year
- CSV export

## Run locally
```bash
npm install
npm start
# open http://localhost:3000
```
